## About the version number
- 版本号格式遵循 `{cate}V{x}.{y}` (例如 `MOSSTagFlowV1.0`)
  - **cate:** 类别代号
  - **x:** 数据集版本
  - **y:** 训练参数/超参数版本
- Version tag follows the format `{cate}V{x}.{y}` (e.g. `MOSSTagFlowV1.0`)
  - **cate:** Category identifier / code
  - **x:** Dataset version
  - **y:** Training parameter / hyperparameter version
